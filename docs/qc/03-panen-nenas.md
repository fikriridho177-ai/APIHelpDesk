# Fase 3 — Panen Nenas: Grid Excel-like, Detail Typed, View Perhitungan

Tanggal: 2026-11-19 · Database: `helpdeskasd` (PostgreSQL) · Status: selesai, build & test hijau.

## 1. Lingkup

Fase 3 mengaktifkan form `QC-PANEN-NNS` (template `12.PANEN NENAS.xls`, sheet `PNN NNS`)
sebagai pola pertama detail typed: grid sampel Excel-like di frontend, penyimpanan baris
sampel pada tabel typed `TrnQcInspSampelPanenNenas` (bukan `DataJson`), dan seluruh
kolom turunan (Total, Tertinggal, %) dihitung di VIEW PostgreSQL — angka mentah saja
yang disimpan. Autosave header+grid, dialog temuan per baris, dan pemetaan export
Excel/PDF ke layout template asli.

## 2. Perubahan skema (migrasi manual)

Script: `sql/2026-11-19-qc-fase3-panen-nenas.sql` (idempotent, tanpa BEGIN/COMMIT internal).
Rollback: `sql/2026-11-19-qc-fase3-panen-nenas-rollback.sql` (transaksi internal + guard data).

- `TrnQcInspSampelPanenNenas`:
  - `Id bigint GENERATED BY DEFAULT AS IDENTITY` PK;
  - `InspectionId bigint` FK → `TrnQcInspection` `ON DELETE CASCADE`;
  - `RowNo int` CHECK 1..20; index unik `(InspectionId, RowNo)`;
  - `NomorJalur varchar(50) NOT NULL`;
  - `JumlahPohon`, `BuahTidakDipetik`, `BuahTelahDipetik`, `BuahTerpotong`
    `int NOT NULL DEFAULT 0` CHECK ≥ 0;
  - `Keterangan varchar(250) NULL`; `CreatedAt timestamptz default now()`.
- View `vwQcPanenNenasDetail`: kolom mentah + turunan
  `TotalBuah`, `BuahTertinggal`, `PersenTertinggal` (ROUND 2 desimal, guard `NULLIF` total=0)
  + kolom header inspeksi.
- View `vwQcPanenNenasRekap`: agregat per inspeksi (COUNT/SUM/COALESCE::int) + header,
  `LEFT JOIN` sampel, `JOIN MstQcForm` filter `Code='QC-PANEN-NNS'`.
- `UPDATE "MstQcForm" SET "Active" = true WHERE "Code" = 'QC-PANEN-NNS';`
  (langkah approval sudah di-seed Fase 1 via CROSS JOIN — tidak perlu seed baru).

## 3. Asumsi rumus (PENTING — template kosong)

Template `12.PANEN NENAS.xls` yang tersedia **kosong tanpa formula**, sehingga semantik
kolom turunan ditetapkan sebagai asumsi dan didokumentasikan di header SQL:

- `TotalBuah = BuahTidakDipetik + BuahTelahDipetik + BuahTerpotong`
- `BuahTertinggal = BuahTidakDipetik + BuahTerpotong`
- `PersenTertinggal = BuahTertinggal / TotalBuah × 100` (ROUND 2 desimal; NULL bila total = 0)

Semantik ini diterapkan **identik** di tiga tempat: VIEW PostgreSQL, model frontend
(`panenNenasModel.ts`), dan pipeline export. Footer total menghitung ulang % dari baris
total (bukan rata-rata % per baris). Standar/target % penerimaan per form masih terbuka
menunggu konfirmasi §6 — belum ada validasi target di Fase 3.

## 4. Alur detail typed (backend)

Kontrak frontend tidak berubah (`data.samples`); backend yang memindah penyimpanan:

- `QcPanenNenasDetail.TryParse` memvalidasi: `nomorJalur` wajib trim ≤ 50; 4 kolom hitung
  wajib integer ≥ 0 (null/'' ditolak; angka string diterima via `int.TryParse` invariant);
  `keterangan` ≤ 250; maksimal 20 baris; `RowNo` = index + 1.
- **Create/Update**: parse + validasi sebelum mutasi; `samples` di-strip dari `DataJson`
  (extras header seperti `umurPanen` tetap disimpan), baris typed ditulis dalam transaksi
  yang sama. Update mengganti baris lama (load + `RemoveRange` + `AddRange`, aman InMemory).
- **GetInspection**: baris typed dibaca urut `RowNo` lalu di-merge kembali sebagai
  `data.samples` via `JsonNode` — bentuk respons sama seperti sebelumnya.
- Kolom turunan tidak pernah dikirim ke backend.

Integrasi: `QcInspectionsController` (Create/Update/GetInspection), entity
`QcInspSampelPanenNenas` (`QcDetailEntities.cs`), `DbSet QcPanenNenasSamples` + konfigurasi
di `AppDbContext.cs` (blok QC; WAD tidak disentuh).

## 5. Frontend

- `qcGridModel.ts` (logika murni): definisi kolom, `intOf`, format id-ID, `isIntCellValid`,
  `emptyGridRow`, `totalsRow` (jumlah kolom int; turunan dihitung dari baris total),
  `parseClipboard`, `applyPaste` (kolom isian saja, auto-expand sampai `maxRows`,
  kolom computed tidak pernah ditulis, catatan truncation).
- `panenNenasModel.ts`: 8 kolom (jalur, jumlah pohon, tdk/tlh/terpotong, total computed,
  % computed, keterangan), `PANEN_NENAS_MAX_ROWS=20`, validasi (min 1, max 20, jalur wajib,
  hitungan wajib integer ≥ 0).
- `QcSampleGrid.tsx` (generik, config-driven): Enter → bawah (tambah baris di akhir bila
  < max), Tab native, Ctrl+V TSV multi-sel/baris, kolom computed & footer total live,
  sel invalid ditandai, tombol Tambah/Hapus/Temuan per baris, readOnly untuk detail/preview.
- `PanenNenasForm.tsx`: input header "Umur Panen" + grid + petunjuk rumus; terdaftar di
  `qcFormRegistry` (validasi + komponen).
- `QcEditInspectionPage.tsx`: autosave debounce 900 ms (baseline `lastSavedRef`, hanya bila
  validasi lolos; status `idle/pending/saving/saved/blocked` + indikator), dialog temuan per

  b terpotong) dari T buah (P% tertinggal).`), severity/target/PIC, panggil `createQcFinding`.
